## Data Dictionary

The page uses Portuguese public copy in a static TypeScript representation
derived from `metadata/canonical/health_regions_v1.yaml`, with 35 fields grouped
as:

- Identification and version.
- Territory.
- Need.
- Capacity.
- Mismatch.
- Spatial analysis.
- Quality.

The dictionary includes client-side search across field name, friendly label,
category, description, and source field. Technical field names, types, and
source fields are preserved. User-facing definitions, interpretations,
limitations, and friendly units are rendered in Portuguese. It explicitly states
that null values are preserved as missing and do not equal zero.

## Publication Policy

The page renders:

`O release analítico atual foi validado, mas ainda não foi publicado publicamente.`

No public download link, local API URL, DOI, public API endpoint, or dataset
license is exposed. License and definitive citation remain release-publication
gaps, not technical bugs.
