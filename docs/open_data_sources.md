# Sources

The release contains derived regional outputs from the locked Mente do Brasil pipeline. Primary official systems are SIM, SIH/SUS, CNES, POPSVS, the DATASUS Health Region crosswalk, SIOPS, IBGE population references, and the WHO standard-population reference. Exact URLs and rights decisions are recorded in `metadata/legal/source_redistribution_matrix_v1.yaml`.

Raw source files, the SIOPS snapshot, POPSBR archives, the validated import bundle, database backups, and scientific geometry are not included.
